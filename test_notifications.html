Notification System Test

To test the notification system:

  1. Open the browser console (F12)
  2. Navigate to Campaign Management
  3. Click "Create Campaign"
  4. Select some screens in the workflow
  5. Click "Next" to generate booking requests
  6. Check console for debug logs
  7. Look for notification bell icon in header
  8. Click the bell to see booking requests
  9. Click Accept/Reject buttons
  10. Watch console for debug logs

Expected Behavior:

  • Console logs should show "Booking request accepted/rejected: [id]"
  • Status should update in notification UI
  • Accepted requests should create payment notifications
  • Notification count should update
